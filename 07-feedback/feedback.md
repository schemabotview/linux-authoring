# Manual learner feedback

- Version: 1.0
- Date: 2026-10-09
- Collection model: users provide feedback manually

## Intake

Users report confusing explanations, errors, unreadable visuals, audio problems, broken links, or requested improvements through an agreed channel. The channel is not selected yet; do not claim an automated feedback or analytics integration exists.

Record the affected course/section ID, website or video URL where relevant, description, optional reproduction details, and release/revision if known. Avoid copying personal information into the public repository.

## Review and correction

The author reviews feedback and decides whether it calls for a correction, clarification, design adjustment, curriculum change, or future-course request. Codex or Claude may assist with analysis and edits when asked; feedback does not automatically rewrite or publish content.

Route changes to the relevant stage. A changed audience, scope, or intended outcome returns to requirements; sequence changes return to planning; presentation changes return to design; content corrections return to implementation and review. Recheck affected assets before republishing.
